# 2R Hockey — test preview

Temporary, self-contained design preview for review on phones and desktop.

- Routes: `/`, `/about`, `/philosophy`, `/sessions`, `/camp`, `/privacy`.
- Forms are intentionally disabled: **no personal data is submitted or stored**.
- Admin, booking slots and payments are not included in this demo.
- Main domain `2rhockey.ru` is unchanged.

Built as a stand-alone visual preview and deployed to Render Static Site.
